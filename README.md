# Missão Aquário Digital

## Descrição

Projeto desenvolvido para monitoramento da qualidade da água do aquário,
com controle dos níveis de pH e temperatura.

## Camadas do Ambiente

### Develop
Ambiente destinado ao desenvolvimento e integração das novas funcionalidades
do sistema.

### Stage
Ambiente destinado aos testes e à homologação das funcionalidades antes
do lançamento em produção.

### Main
Ambiente de produção, contendo as funcionalidades aprovadas e prontas
para utilização.
